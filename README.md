# Supply Chain Analytics Portfolio

Applied projects exploring how data, decision methods, and product thinking can support supply-chain and operations decisions.

I am a PhD student in Information Technology developing practical experience across supply-chain analytics, Python, SQL Server, Power BI, and Excel. Each project begins with a defined operational problem and documents the evidence, assumptions, methodology, limitations, and next steps.

## Projects

### 01. Collaborative Robot Selection for CNC Machine Tending

**Status:** Paper reproduction and methodological audit in progress

This project begins by reproducing and auditing a published entropy-AHP-TOPSIS supplier-selection model. It will then adapt the method into a transparent decision-support concept for selecting a collaborative robot system for CNC machine tending.

Current work includes:

- a formula-driven reproduction of the paper's supplier decision matrix;
- a worked entropy-weight example;
- comparison of published and equation-consistent TOPSIS results;
- documentation of reproducibility gaps and limitations; and
- separation of the original-paper data from the planned robotics extension.

[View Project 01](projects/01-robotics-supplier-selection/)

## Portfolio Principles

- Do not present synthetic data as observed evidence.
- Keep source data, assumptions, and stakeholder judgments distinguishable.
- Treat model rankings as decision support, not automatic decisions.
- Report discrepancies and limitations instead of forcing agreement with a source.
- Connect technical analysis to a specific user and operational decision.
